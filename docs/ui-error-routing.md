# UI 오류 근거와 도구 선택 — 2026-11-01

**agent-desktop을 매일 모든 작업의 기본 도구로 삼을 근거는 아직 없다.**
코드·파일 작업은 기존 CLI/구조화 도구, 웹은 연결된 브라우저 전용 도구를
우선한다. 네이티브 UI 또는 확인된 초기화·도구 연결 장애에는 Codex 전용
agent-desktop을 조건부로 사용한다. 이는 사용자 운영 정책이며 OpenAI의 제3자
도구 추천이 아니다. 실행 기준은 [컴포넌트 가이드](agent-desktop.md)에 둔다.

수로 우열을 판단하지 않는다. 저장소 지침은 웹 페이지 자동화에 브라우저 전용
agent-browser를 안내하고 접근성 미노출 UI를 범위 밖으로 설명한다.
이 설명은 새 패키지를 설치하거나 기존 브라우저를 교체할 권한이 아니다.

v1.0.2에 이 기능이 있다고 주장하거나 제안 코드를 임의로 빌드해 적용하지 않았다.

## 이번 실제 검증

- 설치·이전·복구·해시·정션·전환 판단 자동 검사 17개 통과. 판단 검사에는 여러
  하위 사례가 포함된다. 이를 17회의 실사용 비교로 세지 않는다.
- 첫 장애 재현은 비수신 loopback 소켓에서 연결 거부 대신 타임아웃이 났다.
  전환하지 않고 테스트 창만 종료했다. Codex/방화벽 결함으로 단정하지 않는다.
- 다음 검증은 격리된 TCP 연결을 성립시킨 후 종료해 EOF를 관찰했다. 확인된
  채널 종료 판단 후 agent-desktop으로 테스트 창을 새로 관찰하고 한글 입력,
  정확히 한 번 저장, 결과 읽기, 창 종료, 커서 세션 종료를 확인했다.
- 정책 중단·권한 거부·사람 중단·URL 불명·전달 불명·반복 전환·원인 불명
  타임아웃의 7개 차단 조건에서 데스크톱 호출은 0회였다.
- 적용 전후 확인한 Codex 설정·지침·공유 스킬·Claude 설정 파일의 해시는 같았다.

통제된 연결 장애와 실제 네이티브 동작의 통합 검증이다. 실제 Codex MCP를
고장 내거나 원래 간헐적 웹사이트 오류를 재현한 시험이 아니다. 새 채팅 자동
스킬 선택, 공식 브라우저와 동등 과제 비교, 시각적 캡처는 미검증이다.
실제 토큰 절감·성능 우위·모든 앱 성공을 입증한 것으로 표현하지 않는다.

## 일상 운영과 재평가

```text
작업에 맞는 기본 도구 → 성공 → 결과 확인 → 완료
  실패 → 단계·원인·접근 상태·전달 여부 확인
    정책/권한/사람 중단 또는 URL/결과 불명 → 전환 중단
    기술적 초기화/연결 실패 + 동일 대상 접근 허용 + 미전달 확인
      → 한 번 전환 → 새 관찰 → 원래 작업 → 결과 검증 → 세션 종료
      → 재실패: 추가 전환 없이 남은 작업과 원인 보고
```

사용자가 게임 중이거나 입력을 보존하라고 하면 두 UI 경로 모두 중단한다.
화면 캡처·접근성 관찰·커서 표시·창 활성화·실제 UI 시험을 하지 않고 파일·문서
작업만 진행한다. 게임 종료를 프로세스 감시로 추정하지 않으며 사용자가 제약을
해제한 뒤 재개한다. 이 조건은 별도의 순수 판단 검사로 확인했고 실제 화면은
추가로 조작하지 않았다. headless라는 명칭만으로 비간섭을 보장하지 않는다.

판단 도우미는 진단 자료의 일관성 검사이며 독립적인 권한 집행 시스템이 아니다.
플랫폼 전체 예외를 가로채는 hook이나 상시 서비스는 추가하지 않았다.
실제 허가된 작업에서 새 오류가 발생할 때만 기존 비공개 incident ledger에
표면·버전·단계·정제된 오류 종류·시도·결과를 기록한다. 고객 화면·원문 채팅·
URL·자격 증명은 수집하지 않는다. 유휴 데스크톱을 매일 조작하지 않는다.

특정 앱의 기본 도구를 변경하려면 동일 앱·버전·완료 조건의 실제 작업에서
저장 결과, 실패/수정 횟수, 경과 시간과 관측 가능한 전체 사용량을 비교한다.
권한·대상·도구 버전이 달라지면 관련 근거를 재검토한다. 토큰 미관측은 미상이며
출력 바이트나 커서 표시로 절감률을 계산하지 않는다.
