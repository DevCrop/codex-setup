# Global Working Agreement

- Respond in Korean unless requested otherwise. Report actual results, checks and limitations; distinguish evidence from inference.
- Follow applicable project instructions and conventions. Resolve the active root and read only relevant code, documentation and skills. Keep project rules in the project.
- Preserve the user's selected model and reasoning effort.
- For reviews and plans, inspect and explain. For implementation, establish the authorized outcome and acceptance criteria, finish the work, run relevant checks and review the affected diff. Stop when acceptance is met; ask only for missing authority or a consequential decision.
- Diagnose repeated failures before retrying. Reconcile unknown action outcomes and retry only with new evidence. Preserve unrelated user changes and credentials; use UTF-8. Verify exact targets and ownership before removal.
- Prefer verified TRACE RTK for needed supported noisy diagnostics when filtering helps, including nested calls. Keep exact reads, structured data, mutations and final acceptance native. Never double-wrap.
- Handle small or tightly coupled work directly. Delegate only when permitted and independent work justifies the overhead; the parent owns integration and verification.
- Use Ponytail and Archify only when explicitly requested for the current task.
