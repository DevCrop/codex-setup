# Delegation procedure

Load only for substantial delegation work. Global AGENTS.md owns the decision rule; this guide supplies a handoff format.

```text
Objective:
Relevant instructions and source paths:
Allowed write scope (or read-only):
Acceptance checks:
Return: findings, changed files, checks and unresolved issues.
```

If two tasks share unsettled interfaces or write ownership, settle the contract or run them sequentially. Use built-in agents before introducing another role file. Host capability and higher-priority instructions govern whether delegation can run. The two-child limit and no-recursion default are local operating choices. Delegation can increase total tokens.

Current docs describe manual triggering for Codex surfaces; the enable setting alone is not a guarantee of proactive delegation. A global preference cannot override a host requirement for an explicit delegation request.

Source: [OpenAI subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents).
