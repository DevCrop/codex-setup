다른 프로젝트에서 실행

대상 프로젝트 폴더에서 실행합니다. 러너 위치는 CODEX_HOME을 우선하고, 없으면 사용자 홈의 .codex를 사용합니다.

# PowerShell · 실행 위치: 현재 프로젝트
$traceHome = if ($env:CODEX_HOME) {
    $env:CODEX_HOME
} else {
    Join-Path $env:USERPROFILE '.codex'
}
$traceRunner = Join-Path $traceHome 'bin/trace_rtk.py'

python -B $traceRunner git status
python -B $traceRunner git log -5
python -B $traceRunner git diff
python -B $traceRunner rg "검색어" src
python -B $traceRunner gain --daily --format json

TRACE 체크아웃에서는 python -B scripts/tools.py run git status도 지원합니다. 이 예시는 자동 실행하지 않습니다.

삭제·설치·인증·게시 자동 래핑 금지짧은 출력은 원본 우선

압축된 출력을 다시 RTK로 감싸지 않습니다. 링크 경로·소유권·해시 검사가 실패하면 러너를 우회하지 말고 원인을 확인합니다.

러너가 실행 전에 하는 검사

① CODEX_HOME에서 private 도구 상태 확인 → ② 바이너리·상위 경로의 링크/reparse 경로 거부 → ③ 기록된 소유 경로와 SHA-256 비교 → ④ tsc 요청 시 프로젝트 TypeScript 존재 확인 → ⑤ 현재 프로젝트의 node_modules/.bin을 임시 PATH에서 우선 → ⑥ RTK 텔레메트리와 암묵적인 npm 다운로드를 차단하는 환경 변수 전달 → ⑦ 인자를 직접 전달해 실행하고 반환 코드를 호출자에 전달합니다. 영구 PATH·프로젝트 소스·권한을 변경하지 않습니다. 환경 변수만으로 모든 패키지 도구의 행동까지 보장하지는 않습니다.

기존 훅과 검증된 러너의 차이

현재 호스트의 검증된 러너와 별도 훅을 구분합니다. 훅의 존재·버전과 실제 도구 가로채기는 별도 검증입니다. 기존 훅·신뢰·권한을 보존하며 모든 명령이 자동 압축된다고 가정하지 않습니다.
